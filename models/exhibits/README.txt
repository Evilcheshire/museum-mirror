Тут мають міститися 3D-моделі музейних експонатів (глечики, мечі, інструменти).
Підтримувані формати:

  • .glb / .gltf   — рекомендовано. .gltf може мати зовнішні текстури
                     поряд з файлом (Three.js GLTFLoader їх знайде сам).
                     Підтримується Draco-стиснення.

  • .obj + .mtl    — .obj, .mtl і всі текстури (.png/.jpg) необхідно помістити в одну
                     папку. Шляхи в .mtl мають бути відносні. У items.json
                     можна вказати ключ "mtl", або не вказувати — тоді
                     автоматично шукається <ім'я>.mtl поруч з .obj.

  • .fbx           — бінарний формат, зазвичай з вшитими текстурами.

Після цього їх необхідно зареєструвати у /items.json. у масиві "exhibits".
Приклад для .obj:

  {
    "id": "exhibit-3",
    "label": "Булава",
    "file": "models/exhibits/bulava.obj",
    "mtl":  "models/exhibits/bulava.mtl",
    "offset": [0, 0, 0],
    "rotation": [0, 0, 0],
    "scale": 1.0
  }
